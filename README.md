# Antweight-MeltyBrain
An antweight (1lb) battlebot following the melty brain style. Spins up using two N20 motors attached to foam wheels on a polycarb/PETG sandwich chassis. 

Includes a lightweight configuration where two blades are removed and the remaining two are shifted to the vertical-middle of the robot.
